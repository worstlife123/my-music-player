# Сборка EXE для Windows

1. Установи **Python 3.13 или 3.12, 64-bit** с [python.org](https://www.python.org/downloads/windows/). При установке включи Python Launcher или добавление Python в PATH.
2. Положи `build_exe.bat` рядом с актуальным `player_aurora_smart_beautiful_fixed_ui_repaint.py`. Также поддерживается имя `player.py`.
3. Запусти `build_exe.bat` двойным щелчком и дождись **BUILD SUCCEEDED**. Для установки зависимостей нужен интернет; права администратора не требуются.
4. Готовый плеер: **`dist\AuroraMusicPlayer.exe`**.

Скрипт создаёт отдельное окружение `.build-venv`, устанавливает PyInstaller,
PyQt6, yt-dlp с дополнительными зависимостями и ytmusicapi. Библиотеки Qt для
воспроизведения звука собирает штатный hook PyInstaller. yt-dlp и ytmusicapi
включаются вместе с данными пакетов и динамически загружаемыми модулями.
Если есть папка `fonts`, файлы `.ttf` и `.otf` из неё также попадут в сборку.
При повторной сборке окружение используется снова, зависимости обновляются.

EXE создаётся одним файлом без консольного окна. Для запуска готового файла
Python не нужен. Интернет по-прежнему нужен для онлайн-музыки, а подключение
аккаунтов на другом компьютере выполняется в настройках плеера. Cookies,
кэш лайков и пользовательские настройки скрипт в EXE не добавляет.

Если сборка завершилась ошибкой, окно останется открытым: сохрани текст ошибки.
Если собранный плеер закрывается при запуске, открой CMD в папке проекта и выполни:

```bat
build_exe.bat debug
```

Затем запусти `dist\AuroraMusicPlayer-debug.exe` из CMD. Диагностическая версия
сохраняет консоль, чтобы был виден текст ошибки. Журнал самого плеера:
`%LOCALAPPDATA%\AuroraMusicPlayer\player.log`.

Сборка Windows EXE выполняется на Windows. Проверка исходников и инструкции
в Linux не подтверждают работу готового EXE на Windows.
